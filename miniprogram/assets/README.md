## campus.png 是怎么来的

原图是用户提供的彩色绿线稿（463×419，线色 `#2A7945`），与项目的橄榄绿体系（`--accent-500 #536B59`）不同族。处理成单色蒙版后重染：

```
裁掉截图 3px 暗边
→ 取 min(r,g,b) 通道当"墨的浓度"（绿墨水用 min 比亮度准）
→ 阈值 8 去白底噪点，gamma 0.85 保住淡叶脉
→ trim 白边
→ 在纯白上直接合成 #536B59（不做 alpha 通道）
→ 300×262，48 色，PNG optimize
```

**为什么不留透明通道**：卡片本来就是纯白面，留 alpha 会多一个通道，同为 360px 宽时体积从 82KB 涨到 214KB（比原图还大）。线稿类素材只要底色确定，**烤成白底 RGB 再限色**最省。

## 改图注意

- 换图必须同步改 `home.wxss` 里 `.hero__art` 的 `width`；当前 200rpx（=100px 显示宽）是按"不压到区间文字"算出来的，放大前先看 `.hero.panel--hero > view/button/ruler { z-index:1 }` 那条压层规则还在不在。
- 主包 2MB 上限，这张 57KB 占 2.9%。再加图请先压。
