动效对照

校园请假后台 · 纸感动效层 v1 · 复用 css/motion.css 与 js/motion.js
系统已开启「减少动态」，下面的动效会直接落到终态 —— 这正是 reduced-motion 下应有的表现。
三条曲线、四档时长、位移上限 4px；动效只回答一个问题：刚才发生了什么。 完整决策见 backend/web/MOTION.md，取舍依据见 reviews/motion-ux-audit-2026-10-22.md。

01 · 页面入场

页根 120ms 透明度，页头额外 180ms 上落 4px。只给页头位移，页根不动 —— 页根带 height:100% 还要承接滚动位置恢复，加 transform 会把 sticky 操作条一起卷进动画。同视图内切换（如 /pending → /pending/ext）不播。

02 · 主从列表入场

只动透明度、不做位移：行高 52px、行间只有 1px 分线，逐行上浮会让相邻分线互相追赶。错落 24ms，最多 5 步（24×5＋180＝300ms）。一次性门控 —— 点选另一条时不重播，否则就是"点一下闪一下"。

03 · 抽屉与遮罩

全站唯一的大位移，240ms 保留不动。抽屉用 --ease（前 90ms 走完约七成，读作被推到位），遮罩用 --ease-tog（对称曲线，像覆一张描图纸）；关闭走 --ease-in，尽快把注意力还回去。内容区不做二次入场。

translateX(100%→0) / 240ms --ease　＋　scrim opacity / 240ms --ease-tog

04 · 统计数字落定

320ms 从 0 滚到终值，曲线同 --ease（末段慢下来 = 读数落定）。只对 小于 1000 的纯整数做：四位数带千分位逗号，滚动中途会多一个字符宽度、数字左右跳格。只在首屏进入时做一次，重绘直接落终值。

05 · 图表绘制

折线用 描边生长（pathLength="1" + stroke-dashoffset，纯 CSS，不用量路径长度）；面积延后 100ms 上彩，数据点在 200ms 才出现，三者并行收尾在 320ms。环形图的扇区是 fill 路径没有描边，所以只能分段落墨，不能旋转扫过。

06 · 慢加载骨架

只在启动取数超过 400ms 才出现（更短就是"白块闪一下"，比没有更糟）。不做亮白扫光 —— 那是流光语言，在米绿纸上会出现一条比卡片还亮的带子。改成纸的呼吸：两端同色阶、ΔL≈3%，弱于 1px 分线。

background-color 往返 / 1.8s alternate infinite　·　行间 24ms 错落　·　reduced-motion 下 animation: none

07 · 即时反馈

只动 background-color / border-color / opacity，120ms 对称曲线 —— 可逆状态必须来去同速。按下是 1px 位移，不是缩放。表格行不加过渡：每次重绘都重建 <tr>，新节点没有上一个值，写了也是死代码。

08 · 状态点脉动（严格限量）

默认全站静止。只有显式加了 .is-urgent 的单个逾期状态点才脉动，2 次即停。禁止扩散阴影（那是发光）与缩放（呼吸灯是消费级语言）。一屏 20 个点在闪 = 没有信息。

09 · 下拉菜单

打开 120ms 淡入 + 上落 4px；关闭瞬时。下拉是"我现在就要它消失"，加了退场会让人觉得点击没生效，连点两次时尤其明显。

opacity 0→1 + translateY(-4px→0) / 120ms --ease　·　关闭不加退场
不该动的地方同样重要：搜索/筛选每次按键都整表重建，所以那里一律零动效（180ms 的入场会被 80–150ms 的打字间隔打断，表格会长期停在半透明）； 页面不做退场；卡片不 hover 抬升；数字滚动不用于会变动的计数；百分比不做滚动。完整否决清单见 MOTION.md §5。
