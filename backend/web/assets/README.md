# assets —— 工作台用到的图片

代码里已经写死了下面几个文件名，把同名图片丢进这个目录即可生效，
**不用改代码**。缺图不会报错：头像会回退成姓名首字，插画位留空。

| 文件名 | 用在哪 | 建议尺寸 | 说明 |
|---|---|---|---|
| `avatar.png` | 顶栏右上角用户头像 | 56 × 56 | 正方形，圆形裁切，png 透明底 |
| `avatar-1.png` ~ `avatar-8.png` | 待办卡片里的学生头像 | 80 × 80 | 按学生 id 取模选图，少放几张也能跑 |
| `welcome-bear.png` | 右栏「辛苦了，老师！」卡片右侧 | 200 × 200 | 透明底，底部对齐 |
| `side-art.png` | 侧栏底部的房子/树插画 | 360 × 240 | 透明底，底部对齐 |

## 怎么验证放对了

打开 `http://localhost:8080/admin/?demo=1#/workbench`：

- 头像位出现图片 → `avatar.png` / `avatar-N.png` 放对了
- 右下角卡片右侧出现小熊 → `welcome-bear.png` 放对了
- 侧栏底部出现插画 → `side-art.png` 放对了

## 注意

- 文件名区分大小写，必须全小写
- 改完图片**不用重启后端**，但浏览器有缓存，强制刷新（Ctrl+F5）
- 如果是 svg，也可以直接叫 `.svg` 但要把代码里的扩展名一起改（目前写死 png）
