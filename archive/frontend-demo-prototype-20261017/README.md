# 校园请假 · 学生端 H5 高保真原型

原生 HTML/CSS/JS，**零依赖**（无 CDN、无字体、无图标库、无构建、无 ES module）。
打开方式：① 双击 `index.html`（`file://` 直接跑）；② `python -m http.server 8765` 后访问 `http://127.0.0.1:8765/`。

## 6 条演示脚本（右下「演示」→ 选状态后逐屏操作）
1. **P1 申请→提交**：S1「＋ 申请请假」→ 场景默认未选（点提交报「请选择请假场景」）→ 选「离校」→「事假」→ 结束时间用底部三列滚轮选到跨天（行下出现「共 N 小时 N 分（跨 N 天）」）→ 填理由/去向/电话 → 提交（800ms loading）→ **replace** 为 S4「待审批」，返回直达 S1。
2. **P2 撤回**：演示→「待审批」→ S4 满宽描边「撤回申请」→ 弹窗点「取消」状态不变；再点「撤回」→ 徽章转「已撤回」、时间轴转灰、操作栏消失。
3. **P3 取消**：演示→「已通过」→ S4 描边危险「取消申请」→ 确认后徽章「已取消」、操作栏消失。
4. **P4 校内销假**：演示→「请假中（校内）」→ S4 主「确认结束」→ 确认弹窗 → 徽章一次 scale 回弹、时间轴 4 节点全亮、操作栏消失。
5. **P5 定位销假**：演示→「请假中（离校）」；「定位结果」选「通过」→ S4 主「返校定位并销假」→ S6 呼吸态约 1.5s → ✓「定位校验通过」→ 返回 S4 为「已销假」。选「范围外」→ 红 ! + 两个出口，「重新定位」重跑、「申请人工核验」切 `manual_pending`，**返回 S4 仍是「请假中」**。
6. **P6 续假**：S4 次「申请续假」→ 对比块（左灰右蓝）选新结束时间 + 填原因 → 提交后 pop 回 S4：小徽章「续假待审批」+ 灰字「仍按原结束时间处理」；再进 S5 为只读 + 按钮 disabled；演示「续假状态→续假审批通过」→ 结束时间更新、徽章转「续假已通过」、剩余时长重算。

## 演示控制层（右下「演示」）
模拟时间（真实/固定 09:42/推进到请假中 18:30/推进到逾期 12:30）· 当前申请状态（10 项）· 续假状态（4 项）· 定位结果（通过/范围外/拒绝授权/定位失败）· 登录身份（只读）· 隐藏演示入口 · 重置演示数据。
联动：切状态即时重渲染 S1/S3/S4；「已通过」自动把时间锚到开始前、「请假中」锚到开始后、「逾期」推进到结束时间后 30 分钟，保证状态与时间自洽。

## 已知限制
1. 新增申请只存内存，刷新回到内置数据；演示状态/已读/入口可见性/未读红点开关按 `cl_demo_state`、`cl_demo_visible`、`cl_onboarding_seen`、`cl_settings` 恢复。
2. 「真实时间」取系统时钟时分并锚定演示日 10.16（否则 2026 的演示数据会显示「还剩 364 天」）。
3. 定位为模拟结果，不调用 Geolocation、不展示地图与经纬度。
4. 材料仅本地预览，不校验体积/格式，大图查看用 Toast 占位。
5. 「演示」入口：≥900px 停靠在手机壳右侧外部，壳内零遮挡，论文截图与投屏不受影响；<900px 仍在壳内右下（有操作栏 bottom 96 / tab 页 78），会压住右下 44×44 区域内的内容（如 S9「未读红点提醒」开关），已默认降到 `opacity .45` 降低存在感，长按 800ms 可隐藏，向上滚动即可让出该行。
6. S1 起始时间在「当前正在请假」时自动顺延到上一段结束 +10 分钟（避免默认值必然触发时间冲突）。
