## 这是什么

一个单文件的设计系统展示页（不是业务原型），用于集中查看字号、配色、组件与动效的质感。

打开方式：双击 `index.html`，无需服务、无外部依赖。

## 包含内容

| 区块 | 内容 |
|---|---|
| 封面 | 96px 大字 + 逾期申请卡实物 + 规格标签 |
| 01 字体 | 7 级字阶实物渲染、正文字号 14/15/16 实测切换、tabular-nums 对比 |
| 02 色彩 | 10 级品牌色阶（可复制）、4 组语义色、10 级暖中性、3 套主题实时切换 |
| 03 间距 | 4pt 标尺、圆角 4 档、阴影 2 档（实物） |
| 04 组件 | 按钮 5 类 × 5 态矩阵、7+1 徽章、申请卡、表单全套、Toast/弹窗/tabBar |
| 05 动效 | 4 条缓动曲线可视化 + 播放、stagger、打勾、骨架、悬浮 |
| 06 状态 | 7 主状态 + 逾期叠加 + 色彩映射表 |

三套主题：校园蓝 `#2563C9` / 松青 `#0E7C6B` / 赭石 `#8F4A1C`。

## 与 `prototype/` 的区别

- `prototype/`（根目录）：9 屏业务闭环原型，能点通提交→审批→销假，用于流程验证与答辩演示。
- 本目录：纯设计展示，不能跑业务，只用于判断视觉方向。

## 已知局限（若要重启这一方向）

1. **全部系统字体**：中文没有字型性格，标题与正文只靠字号与字重拉开差距。
2. **形态是"规范文档"，不是"作品"**：信息密度高、版式安全，缺少一个能让人记住的视觉母题。
3. **赭石主题与危险色偏近**：主按钮 `#8F4A1C` 与危险 `#B23A28` 色相差小，同屏需谨慎。
4. **不是真实界面**：没有手机壳、没有真实内容密度，无法判断实际使用时的观感。

## 结论

"中规中矩"的根因不在参数，在方向：蓝 + 白 + 圆角卡片 + 系统字体本身就在模板区间内，继续调字号和间距也跳不出去。若要重做，应该先换一个**视觉母题**（例如校园档案/教务表单的实物语言、或强排版的中文衬线），再谈组件。
