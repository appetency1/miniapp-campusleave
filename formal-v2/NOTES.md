## 二、跑得通的路径

1. **申请 → 提交**：选了场景和类型、填够 5 个字的理由才能交；不齐会逐项标红并提示。提交后 800ms 蒙层 → 直接进详情。
2. **销假**：
   - 离校 → 独立的「返校销假」页（雷达环 + 定位中 / 已确认在校区内 / 不在校区范围内三态）。校验通过 1.1s 后自动回首页，首页落到下一条；范围外可「重新定位」或「申请人工核验」。
   - 校内 → 二次确认后直接结束。
   - 演示面板可切「定位结果：通过 / 范围外」。
3. **撤回 / 取消**：二次确认，状态变更后首页重算。
4. **续假**：改新结束时间 + 校验必须晚于原结束，提交后记录挂 `ext.pending`。
5. **筛选 / 已读 / Esc 返回 / 时间选择器**（快捷项 + 原生日期时间）。

## 五、设计约定

- 纸 `#FBFAF7` / 墨 `#15202E` / 蓝 `#2563C9` / 线 `#E7E3D9`
- 中文 Noto Sans SC，数字与编号 Noto Serif SC
- 圆角统一 6；卡片只在记录页出现；其余靠 1px 细线分区
- 主按钮墨色实心，蓝色只给状态、刻度尺、tab 选中
- 触控目标 ≥44；`:focus-visible` 可见；`prefers-reduced-motion` 降级
