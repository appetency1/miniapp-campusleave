# 首页定稿 Brief · 校园请假学生端

> 用途：直接照着做前端。所有数值单位为 px（375 视口），小程序按 1px = 2rpx 换算。
> 范围：**只定首页**，但第 9 节给出从首页推导的全局规则，其余页面据此延伸。

---

## 0. 一句话

**像一个知道你在哪、还剩多久、下一步该干嘛的私人助理——不是一台办事机器。**

三条不可让步的判断：

1. **未请假 → 第一眼是"请假按钮"**；已请假 → 第一眼是"剩余时间"。首页结构随状态分叉，不是固定布局。
2. **温暖来自底色，不来自主色**。页面底 `#FAF8F3`（暖米白），不是纯白。
3. **角色只在三个时刻出现**，其余时间让位给信息。

## 1. 色板

| Token | HEX | 用途 | 用量 |
|---|---|---|---|
| `--bg` | `#FAF8F3` | 页面底 | 满屏 |
| `--surface` | `#FFFFFF` | 卡片、抽屉、输入区 | 局部 |
| `--ink` | `#1A1D1A` | 主文字、大数字 | 主要 |
| `--ink-2` | `#5C635C` | 次要说明、副文案 | 中等 |
| `--ink-3` | `#9AA097` | 标签、单位、时间轴两端 | 少量 |
| `--line` | `#E8E3D8` | 分隔线、卡片描边 | 极细 |
| `--brand` | `#1F4A3D` | 主色：主按钮、进度填充、角色 | 关键处 |
| `--brand-press` | `#163A2F` | 主按钮按下 | — |
| `--brand-tint` | `#E7EFE9` | 主色淡底（选中态/徽章底） | 极少 |
| `--accent` | `#E08B3C` | 强调：状态词、逾期倒计时、提醒 | **≤5% 面积** |
| `--accent-tint` | `#FBEEE0` | 强调淡底 | 极少 |
| `--danger` | `#B3402F` | 逾期、驳回 | 仅异常态 |
| `--danger-tint` | `#F7E6E2` | 异常提示条底 | 仅异常态 |

**规则**
- 一屏最多出现 2 个彩色（brand + accent），其余全是中性色。
- accent 只允许出现在：状态词、逾期数字、"记得销假"提示。
- 禁止：蓝色（`#2563C9` / `#3B5BFF` / `#1677FF`）、大面积橙、任何渐变背景。

## 2. 字体

字体栈（无外部依赖，小程序原生可用）：

```
PingFang SC, HarmonyOS Sans SC, Source Han Sans SC, Noto Sans SC, Microsoft YaHei, sans-serif
```

等宽（数字专用）：

```
ui-monospace, SF Mono, Cascadia Mono, Menlo, Consolas, monospace
```

| 级别 | 字号/行高 | 字重 | 字距 | 用途 |
|---|---|---|---|---|
| **Display** | 76 / 76 | 500（等宽） | -2 | 剩余时间 `6:12` |
| **H1** | 30 / 38 | 800 | -0.5 | 状态词「请假中」 |
| **H2** | 22 / 30 | 700 | -0.3 | 次级标题「等待李老师审批」 |
| **H3** | 17 / 24 | 600 | 0 | 卡片标题 |
| **Body** | 14 / 22 | 400 | 0 | 正文 |
| **Aux** | 12 / 18 | 400 | 0 | 副文案、说明 |
| **Tag** | 10 / 14 | 600 | +1.6 | 标签（全大写或加空格） |

**数字规则**
- 所有时间、日期、编号、百分比用等宽 + `tabular-nums`。
- 时间格式：`10.16 18:00`（紧凑）/ `10月17日 周五`（头部）。
- 剩余时间格式：`6:12`，不足 1 小时显示 `42`（分钟），超 24 小时显示 `1天6时`。

### 4.2 主角区 · 状态 A：有进行中的请假（默认主态）

```
y=196  请假中 · 离校 · 事假              11/16 600 accent   字距 +1.2
y=220  6:12                             76/76 500 等宽 brand      字距 -2
y=302  小时 : 分                         10/14 500 ink-3    字距 +1.6
y=330  10.16 18:00 — 10.17 12:00        12/18 ink-2       等宽
y=368  进度条 335×6 r3
       底 #EDE9DF，填充 brand，宽度 = 已过比例
y=382  两端标签 10/14 ink-3：左「已过 11 小时」右「共 18 小时」
```

进度条规格：
- 高 6，圆角 3，容器宽 335（满宽）

- 标签行：`已逾期 · 离校 · 事假`，色改 `--danger`
- 大数字：色改 `--danger`，格式 `+0:32`（加号表示超出）
- 单位行：`小时 : 分 · 已超过批准结束`
- 进度条：填充 100%，色改 `--danger`，右端加一个 8px 圆点
- y=330 下方插入 40 高提示条：底 `--danger-tint`，左 2px `--danger` 竖条，文字 `12:00 前未返校，请尽快销假` 12/20 `--danger`

## 5. 角色规格

**定位**：状态表情，不是吉祥物。常驻会抢信息。

**技术**：纯 SVG，线描，`stroke-width: 2.5`，`stroke-linecap: round`，单色 `--brand`。**禁止**：3D、高光、渐变填充、emoji、写实。

**尺寸**：80×96，基准网格 80×96，头身比 1 : 1.4。

| 状态 | 出现条件 | 动作 | 说明 |
|---|---|---|---|
| **招手** | 无请假 | 右手 3s 一次小摆（rotate -8°→8°） | 头微倾，眼睛两个 3px 圆点 |
| **走路** | — | 不出现（有请假时让位给数字） | — |
| **庆祝** | COMPLETED 后首次进入 | 双手上举 + 一次 scale 1→1.08→1 | 进入后 800ms 内播完，不循环 |
| **着急** | OVERDUE | 头顶三条短线闪烁 + 身体左右微摆 | 颜色改 `--danger` |

**呼吸**：所有状态都有 `translateY 0 → -3px`，2.8s `ease-in-out infinite`。

**画法提示**（给 SVG 实现）：
- 头：圆角矩形 44×42 r20
- 身体：梯形/圆角矩形 36×34 r14
- 眼睛：两个 3.5px 实心圆，间距 12
- 嘴：2.5px 弧线，宽 10
- 四肢：2.5px 圆头线，长 18–22
- 不做手指、不做衣服细节

## 6. 动效

| 场景 | 属性 | 时长 | 曲线 | 备注 |
|---|---|---|---|---|
| 进页（元素依次浮现） | opacity 0→1, translateY 10→0 | 420ms | `cubic-bezier(.2,0,0,1)` | 相邻元素延迟 60ms，最多 6 个 |
| 剩余时间跳动 | 每位 translateY 100%→0 / 旧位 -100% | 380ms | `cubic-bezier(.32,.72,0,1)` | 每秒一次，只动变化的位 |
| 进度条生长 | width 0 → 目标 | 900ms | `cubic-bezier(.2,0,0,1)` | 延迟 200ms 启动 |
| 进度条流动（生命感） | 内部高光 translateX -100%→100% | 3.2s | `linear infinite` | 1px 宽的白色 30% 竖向高光，极淡 |
| 角色呼吸 | translateY 0→-3px | 2.8s | `ease-in-out infinite` | — |
| 角色招手 | rotate -8°→8° | 900ms | `ease-in-out infinite` | 每 3s 一轮 |
| 按钮按下 | scale 1→.97 | 120ms | `ease-out` | 松开回弹 160ms `cubic-bezier(.34,1.2,.64,1)` |
| 状态切换 | 内容 opacity 交叉 + 卡片 scale .98→1 | 300ms | `cubic-bezier(.34,1.2,.64,1)` | 提交成功回首页时触发一次 |

**原则**
- 动效只发生在**状态变化**和**时间流动**两件事上，不做装饰性动画。
- 所有动画必须带 `prefers-reduced-motion: reduce` 降级（`.01ms`）。
- 小程序只能用 `transform` / `opacity` / `width`（少量），禁用 `filter`、`backdrop-filter`、`mix-blend-mode`。

## 7. 小程序落地清单

| 能 | 不能 | 替代 |
|---|---|---|
| `linear-gradient` | `backdrop-filter` | 改用 `rgba` 半透明底 + 1px 白边 |
| `transform` / `opacity` | `mix-blend-mode` | 直接给目标色 |
| `box-shadow` 单层 | 多层叠加阴影 | 单层 + 描边 |
| `@keyframes` | `filter: blur()` | 用径向渐变模拟柔光 |
| SVG 内联（`<image>` 或 base64） | `<filter>` 雪碧图 | 简化 SVG，去 `feDropShadow` |
| `rpx` 换算 | 超过 3 层的 `position: absolute` | 用 flex 布局 |

**换算**：本文所有 px × 2 = rpx。

**注意**：SVG 里的 `feDropShadow` 在小程序 `image` 模式下不生效，角色与图标用纯 path + stroke，不加滤镜。

---

## 8. 禁忌清单

1. **不要蓝色**（`#2563C9` / `#3B5BFF` / `#1677FF`）——这是你前 18 版被否的共同点之一。
2. **不要纯白底**（`#FFF` 满屏）——用 `#FAF8F3`。
3. **不要库存照片**做背景——照片会把"助理感"变成"海报感"。
4. **不要让角色常驻**——它只在空态/完成/逾期出现。
5. **不要超过 3 种彩色**——brand、accent、danger，三选二。
6. **不要圆角 > 20**（按钮胶囊除外）——大圆角会滑向"消费类 App"。
7. **不要 emoji 当图标**——所有图形用 SVG 线条。
8. **不要"审批人：李建国"这种公文措辞**——用"李老师"。
9. **不要进度环 + 进度条同时出现**——一屏只用一个进度表达。
10. **不要动效超过 3 处同时运行**——生命感来自"少而持续"，不是"多而热闹"。

## 9. 从首页推导的全局规则（其余 5 屏照此延伸）

1. **每屏都有 Head 区**：日期行 + 一句人话（欢迎语/状态句/引导句）。但角色只出现在首页。
2. **所有时间用等宽数字**，字号至少比同层级中文字大 1.5 倍。
3. **主操作永远是底部胶囊实心按钮**，宽度 335，高 54，距底 32。
4. **状态靠文字 + 颜色表达，不靠图标**。图标只用于导航和功能入口。
5. **卡片白底 + 1px 线 + 16 圆角 + 无阴影**。不要给卡片加彩色左边框。
6. **一屏只讲一件事**：申请页只讲"两种场景的区别"，详情页只讲"这段时间发生了什么"，记录页只讲"哪些还在进行"。
7. **所有空态都配一句人话 + 一个动作**，不写"暂无数据"。
8. **accent（暖橙）只用于"现在要做的事"**，不用于装饰。
