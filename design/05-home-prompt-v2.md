# 首页改版 · 生图提示词（不改大方向）

## 边界

**大方向不动**：仍是蓝白机构体系——品牌蓝 `#2563C9`、页面底 `#F5F7FA`、正文 `#121A26`、圆角 12、页边距 20、苹方/思源黑体、数字等宽。

**只动首页的版式**，动的是三件事：

1. 状态从「卡片里的一块」提到**通栏浅蓝色带**——左右出血、无圆角，成为页面顶部的一段"头"。
2. 「审批 / 销假」从卡片底部的两行签署改成**一条两列的细线信息条**——不再有卡片盒子包着它。
3. 主按钮紧跟信息条，页面从"三层卡片"变成"色带 → 细线条 → 按钮"三级节奏。

结果：一屏只有一个焦点（剩余时间），卡片的数量从 3 个降到 1 个。

## 出图后怎么判断

1. **色带是否通栏**：浅蓝必须顶到屏幕左右边缘，不是一张带圆角的卡。这一条不对，整版就退回旧结构。
2. **焦点是否唯一**：眯眼看只剩 `05:29` 和蓝色按钮两个重元素，其余都退后。
3. **卡片数量**：全页只允许「最近记录」这两张白卡。其他位置出现盒子，错。
