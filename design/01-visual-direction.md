# 学生端 H5 视觉设计系统 V1.0 · 清爽校园蓝

> 交付对象：UX（页面与交互规范）、FE（H5 高保真原型）。视口 375×812，模拟微信小程序外壳。
> 本文件只定义视觉方向与 token，不含组件 HTML/CSS 实现（token 块除外）。

---

## 1. 设计定位与视觉原则

**一句话定位**：像学校官方通知一样可信，像教务系统一样清楚，但比两者都轻——用低饱和蓝白、去阴影的平面分层和克制的状态色，把「审批在走」这件事讲明白。

| # | 原则 | 解释 |
|---|---|---|
| P1 | **状态先于装饰** | 每屏第一眼必须能答出「我现在是什么状态、下一步该做什么」；任何图形、渐变、动效都不得抢占状态与时间的视觉权重。 |
| P2 | **两档色，不铺满** | 界面 90% 面积只用中性色（白 / #F5F7FA / #EDF0F5），彩色只出现在状态徽章、主按钮、场景标签三处；一个屏幕内高饱和色块不超过 2 个。 |
| P3 | **用描边和留白分层，不用阴影** | 卡片靠白底 + 1px 描边 + 底灰对比分层；阴影只留给真正的浮层（弹窗、Toast、动作面板），避免「满屏浮起」的模板感。 |

**明确避免**：蓝色渐变按钮、大圆角卡片 + 重阴影组合、emoji 与拟人吉祥物、彩色图标、7 个状态各用一种高饱和色、首页大插画占屏超过 120px、圆角 999px 的胶囊型徽章。

## 3. 字体系统

**字体栈**（无外部字体依赖）：
`-apple-system, BlinkMacSystemFont, "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", "Source Han Sans SC", sans-serif`

| 级别 | Token | size / line-height | weight | 用途 |
|---|---|---|---|---|
| Display | `--cl-fs-display` | 28 / 36 | 700 | 首页剩余时长、统计数字（数字场景可到 32） |
| H1 | `--cl-fs-h1` | 24 / 32 | 600 | 页面大标题：结果页、定位销假页（**表单页不用 H1**，避免与 17px 导航标题形成双字号） |
| H2 | `--cl-fs-h2` | 17 / 24 | 600 | 区块标题、导航标题、卡片时间段 |
| Body | `--cl-fs-body` | 15 / 24 | 400 | 正文、表单值、列表主信息 |
| Aux | `--cl-fs-aux` | 13 / 20 | 400 | 辅助说明、驳回原因、卡片次要行 |
| Tag | `--cl-fs-tag` | 12 / 16 | 500 | 状态徽章、场景标签、字符计数 |
| Nav | `--cl-fs-nav` | 10 / 12 | 500 | tabBar 标签 |

- 字重只用 400 / 500 / 600 / 700 四档，禁止 300 与 800（中文字重断层明显）。
- 中文标题不用 `letter-spacing` 负值；徽章与标签加 `0.2px` 正字距提升小字号辨识度。**紧凑行高变体**只允许两种：`15/20`（场景卡标题、分段控件）、`13/18`（卡片行 1），不用于正文段落。
- **数字处理**：所有时间、日期、编号、计数、统计值统一 `font-variant-numeric: tabular-nums;`，保证列表纵向对齐；统计大数字额外 `letter-spacing: -0.5px`。
- **时间格式**：`10.16 周五 18:00`（列表紧凑）／`10月16日 周五 18:00`（详情与表单）。区间用 `—`（em dash，前后各 1 空格），跨天在列表中换行且第二行不缩进。中文与数字之间不加空格；标题不加标点；正文标点用全角。

## 4. 间距与栅格

- **基准 4pt**。标尺：`2 / 4 / 6 / 8 / 10 / 12 / 16 / 20 / 24 / 32 / 40`，禁止出现 5、7、14、18 等非标尺值（1px 描边与 3px 图标微调除外）。
- **页面左右边距 20px**（375 视口，内容宽 335）。
- **卡片内边距 16px**；紧凑列表项 14px；卡片间距 12px（同组）/ 24px（跨语义组）。
- **列表行高**：单行 56 / 双行 72 / 三行及以上 88；表单行 56；详情信息行（label-value）48；tabBar 50 + 安全区。
- **栅格**：单列流式布局，不使用 12 栏。卡片内并列用 flex + `gap:10px`；场景选择 2 列（各 162.5）；统计 4 列等分 `gap:8px`。响应式基准 375：`≥414` 页面边距升 24px、字号不变；`≤360` 场景卡改纵向堆叠、统计 4 列改 2×2。
- **垂直节奏**：首屏内容从导航下 12px 开始；区块标题与内容间距 8px；底部操作栏存在时，滚动区 `padding-bottom: 80px`。

## 5. 圆角 / 阴影 / 描边

| 类型 | Token | 值 | 适用 |
|---|---|---|---|
| 圆角 S | `--cl-radius-sm` | 6px | 徽章、场景标签、字符计数框 |
| 圆角 M | `--cl-radius-md` | 10px | 按钮、输入框、上传位、时间轴节点 |
| 圆角 L | `--cl-radius-lg` | 12px | 卡片、场景选择卡、消息项 |
| 圆角 XL | `--cl-radius-xl` | 16px | 弹窗、底部动作面板 |
| 全圆 | `--cl-radius-full` | 999px | 仅头像、红点、数量气泡 |

- **阴影只 2 档**：`--cl-shadow-1: 0 2px 8px rgba(18,26,38,.06)`（Toast / 吸顶栏 / 悬浮元素）；`--cl-shadow-2: 0 8px 24px rgba(18,26,38,.10)`（弹窗 / 动作面板 / 遮罩层内容）。
- **卡片不用阴影**：白卡片置于 `#F5F7FA` 页面底上即完成分层；卡片内嵌套区块用 `#EDF0F5` 填充而非再加描边。
- **描边统一 1px**（`box-shadow: inset 0 0 0 1px` 或 `1px solid` 均可，禁止 0.5px 以免安卓变粗）：默认结构描边 `#E2E7EF`；分隔线 `#EDF0F5`；选中描边 `#2563C9`；错误描边 `#C0281E`；上传虚线 `1px dashed #CFD6E2`。
- **图标**：内联 SVG，`viewBox 0 0 24 24`，`stroke-width 1.6`，`stroke-linecap/join: round`，`stroke: currentColor`，无填充（除实心点/勾选圆）；尺寸只用 16 / 20 / 24 / 32。

## 6. 组件视觉规范

### 6.1 底部 tabBar
- 高 50px + `env(safe-area-inset-bottom)`；白底；`border-top: 1px solid #E2E7EF`；无阴影，不透明（避免滚动内容透出）。
- 图标 24×24（线性），标签 10/12·500，图标与标签间距 3px，单 tab 热区 93.75×50。
- 未选中：图标与文字同色 `#6B7688`。选中：图标与文字同色 `#2563C9`，无背景块、无加粗跳变（避免列表页切换时抖动）。按下态：图标与文字 `opacity .6`，**不加**背景色块。
- 未读红点：8px 实心 `#C0281E`，1.5px `#FFFFFF` 描边，锚定「消息」图标右上 `translate(6px,-4px)`；未读数 >0 时用高 16 的 pill（`#C0281E` 底、9px 白字、`padding 0 4px`）显示 1–99 / `99+`；受「我的 → 未读红点提醒」开关控制，关闭即隐藏红点/pill，图标与文字不变色。

### 6.2 顶部导航
- 结构：状态栏 44px（静态展示时间/信号，不交互）+ 自定义导航 44px；滚动后导航下方出现 `1px #E2E7EF`，未滚动无分割线；页面底色为 `#F5F7FA` 时导航仍为 `#FFFFFF`，形成顶部白色安全区。
- 标题 17/24·600 `#121A26` 居中，单行溢出省略，最大宽度 `375-96-96=183px`。
- 返回：24×24 chevron-left `#232D3D`，热区 44×44，`left: 8px`；首屏无返回时该位留空。
- **胶囊避让**：右上预留 96×44 不可点击区（小程序胶囊 87×32，`right:7px`，垂直居中于导航条）。右侧若有页面级操作（如「全部已读」），用 15px 文字按钮，横向位置贴胶囊左侧并留 8px 间隙。

### 6.3 状态徽章 badge（含 OVERDUE 叠加）
- 主徽章：高 22px，`padding 0 8px`，`radius 6px`，12/16·600，无描边、无圆点（颜色即语义）。**不使用 999px 胶囊**，与卡片 12px 圆角形成层级区分。
- 续假徽章：高 18px，`padding 0 5px`，`radius 4px`，12/16·600（字号不降，只降高度与内距），必须含「续假」二字，与主徽章横向排列时用 6px 间距。
- **OVERDUE 叠加规则（三重、均不与主状态争位）**：
  1. **形态区分**：逾期标记为「1px `#C0281E` 描边 + 透明底 + 12px 内联警告三角（stroke 1.6）+ 文字 `#C0281E`」，高 22px 与主徽章等高；实心 vs 描边 → 主状态是「当前是什么」，逾期是「超出边界」。视觉读序 `⚠ 逾期 | 请假中`（描边在左，实心在右，右对齐成组）。
  2. **卡片级强化**：卡片贴左边缘加 2px 宽 `#C0281E` 竖条（高 = 卡片内容高 − 24px，`radius 2px`），不侵占内边距。
  3. **一层文字兜底**：卡片第二行时间区间右侧补 12px `#C0281E` 文案「已超 32 分钟」，详情页顶部再加一条 `#FDEDEC` 通栏提示条。
  4. 补销假后撤销标记，**不保留任何红色残留**。

### 6.4 申请卡片（列表项）
- 白底、`radius 12px`、`padding 16px`、无描边无阴影、卡间距 10px；按下态整卡背景 `#F5F7FA`（不做 scale）。
- 行 1（高 22）：左 = 场景标签（6px 色点 + 12/16·500；离校 `#0C6A83`、校内 `#1F55AD`）+ 分隔点 `·` + 请假类型 13/18·500 `#3B4557`；右 = 徽章组（逾期描边 + 主徽章，右对齐）。
- 行 2（视觉重心，`margin-top 8px`）：时间段 17/24·600 `#121A26` + `tabular-nums`，格式 `10.16 周五 18:00 — 10.17 周六 12:00`，跨行时第二行不缩进。
- 行 3（`margin-top 12px`，高 20）**三节点时间轴**：节点 6px 圆（已完成实心 `#2563C9`，当前节点 12px 外环 `rgba(37,99,201,.12)` + 6px 实心，未达 6px 空心 1.5px `#CFD6E2`），连接线 1.5px `#E2E7EF` / 已完成 `#2563C9`；下方标签 12/16·500 `#5A6577`（提交 / 审批 / 结束）。驳回与撤回状态下时间轴只画到第 2 节点并整条转灰。
- 行 4（可选，`margin-top 8px`）：驳回原因首行 13/20 `#5A6577`（`REJECTED` 必显），或申请时间 12/16 `#78849A`。
- 整卡为一个热区；右侧不放箭头（避免与徽章抢位），靠卡片按压反馈表达可点。

### 6.6 表单控件（顺序：场景 → 类型 → 时间 → 理由 → 去向/电话 → 材料）

## 8. 校园角色的处理

**做法**：首页问候区左侧一个 **56×56 圆形图形**（`#EEF3FB` 底，内嵌 32×32 线性校园符号：校门拱形 / 展开的书 / 钟楼，`stroke 1.6`、`#2563C9`），右侧两行文字——第一行 15/24·600 `#121A26` 说状态，第二行 13/20 `#5A6577` 给下一步。图形随状态**换图标不换布局**，尺寸恒定，占屏高 56px（含上下 margin 共 72px）。

**4 种状态文案**

| 状态 | 第一行（15/600） | 第二行（13 灰） | 图标 |
|---|---|---|---|
| 无请假 | 今天没有请假安排 | 需要时从下方发起申请 | 校门 |
| 待审批 | 有 1 条申请等待审批 | 辅导员处理后会通知你 | 时钟/书 |
| 请假中 | 请假中 · 还剩 6 小时 | 返校后记得定位销假 | 门/门牌 |
| 已销假 | 上次请假已正常销假 | 记录已归档，可随时查看 | 打勾的书 |

**明确禁止**：五官与表情、对话气泡、逐帧动画、语音式文案（「我一直在这里陪你」）、彩色渐变身体、占屏超过 72px、出现在申请/审批/销假等操作路径中（仅首页问候区与提交成功的结果反馈可用）。

## 9. 动效规范

| 场景 | 时长 | 缓动 | 描述 |
|---|---|---|---|
| 颜色/徽章/边框切换 | 120ms | `cubic-bezier(.2,0,0,1)` | 仅过渡 color / background / box-shadow |
| 列表首屏进入 | 200ms | `cubic-bezier(.32,.72,0,1)` | `translateY(8px)→0` + `opacity 0→1`，仅前 6 项，stagger 40ms |
| Toast / 展开收起 | 200ms | `cubic-bezier(.2,0,0,1)` | 位移 8px + 淡入 |
| 页面转场（push） | 300ms | `cubic-bezier(.32,.72,0,1)` | 新页 `translateX(24px)→0` + 淡入，旧页不动（模拟小程序栈） |
| 动作面板/弹窗 | 300ms | `cubic-bezier(.32,.72,0,1)` | 遮罩淡入 + 内容 `translateY(16px)→0`；关闭 200ms `cubic-bezier(.4,0,1,1)` |
| 状态变更反馈 | 200ms | `cubic-bezier(.34,1.3,.64,1)` | 徽章一次 `scale 1→1.06→1`，仅详情页；列表不做 |
| 成功打勾 | 200 + 400ms | `ease-out` | 圆底 `scale .8→1`（200ms），路径 `stroke-dashoffset` 绘制（400ms），停留 600ms 后转结果文案 |

- **reduced-motion 降级**：`@media (prefers-reduced-motion: reduce)` 下所有时长压到 1ms 且只保留 opacity；取消位移、scale 回弹、stagger、呼吸态、shimmer（改用静态 `#EDF0F5`）；打勾动画直接跳到完成帧。全局只用 `transition` 与少量 `@keyframes`，不引入动画库；同屏并行动画元素 ≤ 3。
