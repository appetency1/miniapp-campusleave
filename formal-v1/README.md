## 版本是怎么走的

V1 准假单（10-19，6 屏齐活）→ 首页被判「还是一叠卡 + 大按钮，只换了内容没换骨架」→ 改成单屏重做，同一天出四版：

`v2` 换分区（卡片 → 色带）→ `v3` 加交互质感（材质、跟手、数字滚动）→ `v4` 换记忆点（进度条 → 刻度尺）→ `v5` 收 AI 感（去发光、记录改台账行、补页脚）。

每一版的反馈都并进了下一版，v5 是累积结果。v2–v4 保留是为了能回看「哪一步改对了」。

## 三条已定的取舍（后续别再犯）

1. **方向不动**：蓝白机构体系 `#2563C9` / `#F5F7FA` / `#121A26`，圆角 12，页边距 20。只改版式。
2. **AI 感五件套一律不用**：发光投影、大圆角、宽字距、卡片列表、右箭头。
3. **一屏只讲一件事**：首页回答「还剩多久、下一步做什么」，时间轴归详情。
